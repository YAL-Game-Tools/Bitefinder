This is a filterable table with Pathfinder 2nd Edition's various weapons that can be accessed through the ancestral weapon feats!

What's this for?
  • Monastic Weaponry allows to use ancestral weapons for Monk features, so long as they are Agile or Finesse (filter)
  • Some classes don't gain critical specialization, whereas ancestral weapon feats usually offer it at level 5.
  • Some classes don't start with martial weapon training, whereas ancestral weapon feats offer familiarity.
  • For classes that do start with martial weapon training, you can get yourself an advanced weapon instead! These typically punch slightly above their weight class or have something interesting going on for them.
Special cases
  • Unconventional Weaponry (Human) allows to gain familiarity with weapons from other ancestries or ones that are "common in another culture".
  • Samsaran Weapon Memory allows to pick two ancestry-traited weapons.
